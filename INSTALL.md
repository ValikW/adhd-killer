# Как установить СДВГ Киллер

Займёт 5–10 минут. Ничего не нужно понимать в программировании.

**Что понадобится:**
- Mac с macOS 13 Ventura или новее (меню  → «Об этом Mac» покажет версию);
- банковская карта, чтобы пополнить счёт Anthropic на $5 — этого хватит надолго.

---

## Шаг 1. Получи ключ Anthropic

Ключ — это пароль, по которому программа обращается к нейросети Claude.
За каждую проверку экрана списываются доли цента с твоего счёта.

1. Открой [console.anthropic.com](https://console.anthropic.com) и зарегистрируйся
   (можно через Google).
2. Слева открой **Billing** (Оплата) → **Add credits** и пополни на **$5**.
   Без пополнения ключ работать не будет.
3. Слева открой **API keys** → **Create key**. Назови, например, `sdvg-killer`
   → **Create**.
4. Нажми **Copy**. Ключ начинается с `sk-ant-…`.
   Сохрани его в заметки: второй раз сайт его не покажет.

> Сколько это стоит: при обычной работе 20–50 проверок в день — это 3–8 центов.
> Сколько потрачено сегодня, видно прямо в меню программы.

## Шаг 2. Установи программу

1. Открой **Терминал**: нажми `⌘ Пробел`, напиши `Терминал` и нажми Enter.
2. Скопируй эту строку, вставь в Терминал (`⌘ V`) и нажми Enter:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/ValikW/adhd-killer/main/install.sh | bash
   ```

3. Через несколько секунд появится надпись **«Готово»**, а в строке меню
   вверху экрана — значок прицела ◎. Терминал можно закрыть.

## Шаг 3. Первый запуск

1. Появится окно **«Привет! Я СДВГ Киллер»** → нажми **«Ввести ключ»**.
2. Вставь ключ из шага 1 (`⌘ V`) → **OK**.
3. Напиши, чем занимаешься прямо сейчас, например «написать пост про запуск» → **OK**.

## Шаг 4. Разреши доступ к окнам

Программе нужно видеть, какое окно у тебя открыто. macOS спросит разрешение сама.

1. В окне macOS нажми **«Открыть Системные настройки»**.
   Если окно не появилось: меню  → **Системные настройки** →
   **Конфиденциальность и безопасность** → **Универсальный доступ**.
2. Включи переключатель у **СДВГ Киллер**. Mac может попросить пароль.

Готово. Значок ◎ больше не на паузе — программа следит.

## Как пользоваться

Нажми на значок ◎ в строке меню:

| Пункт | Что делает |
|---|---|
| **Сменить задачу** | одна текущая задача, всё остальное — отвлечение |
| **Задача сделана** | закрыть задачу и сразу указать следующую |
| **Это работа** | программа ошиблась — это окно до конца дня считается работой |
| **Перерыв 15 минут** | молчит четверть часа |
| **Звук** | свой звук для мягкого и жёсткого предупреждения |
| **Слежка включена** | выключить совсем |

Через **1 минуту** не по делу края экрана начинают мягко краснеть и звучит сигнал.
Через **2 минуты** — мигают сильнее, и сигнал повторяется. Вернулся к задаче — всё гаснет.
Если нажать на окошко с фразой в правом нижнем углу, появятся те же кнопки.

## Если что-то не так

**Значка нет в строке меню.** На Маках с «чёлкой» значки могут прятаться за ней,
если их много. Убери лишние значки (держи `⌘` и перетащи их вниз) или запусти
программу ещё раз: Launchpad → **СДВГ Киллер**.

**В меню написано «Нет доступа к окнам».** Повтори шаг 4. Если переключатель уже
включён — выключи его и включи снова, потом в меню программы нажми **Выйти** и
запусти её заново.

**«Ошибка: ключ API отклонён».** Ключ скопирован не полностью или удалён на сайте.
Создай новый (шаг 1) и вставь через меню → **Ключ Anthropic API…**.

**«Ошибка: … credit balance is too low».** Закончились деньги на счёте Anthropic —
пополни в **Billing**.

**Ругается не по делу.** Пиши задачу конкретнее: не «работа», а «монтаж рилса в CapCut».
Для окна, которое точно рабочее, нажми **«Это работа»**.

## Обновить

Та же команда из шага 2 — она ставит последнюю версию. Ключ и настройки сохранятся.

## Удалить

```bash
curl -fsSL https://raw.githubusercontent.com/ValikW/adhd-killer/main/uninstall.sh | bash
```

## Что программа отправляет в интернет

В Anthropic уходят только **название программы, заголовок окна, адрес сайта** и текст
твоей задачи. Скриншоты не делаются, текст внутри окон не читается, менеджеры паролей
пропускаются. Ключ хранится только на твоём Маке.
Не включай слежку, когда на экране то, что нельзя показывать посторонним.
